Two-Sentence Horror — a horror story in exactly two sentences, written by a small deterministic program. The locks are undone every morning; this morning there were three. The second sentence is the turn: what has been coming in every night has started locking the narrator in.

## Run it

```sh
node main.ts
```

The program writes the story to `/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR` overrides the directory). No network, no randomness, no clock: every run writes the same bytes.
